Learning goals

Practice recognizing common errors in multivariable differential calculus using the terminology and notation of the course: domains and limits, partial derivatives, gradients and Hessian matrices, Jacobian matrices, the chain rule, and linear approximation.

  • Limit check: a limit is a fixed output value; continuity additionally checks the value at the point.
  • Shape check: Jacobian-matrix rows correspond to output components and columns to input coordinates.
  • Anchor check: a linear approximation satisfies \(L(\mathbf a)=F(\mathbf a)\).
