GRAM-SCHMIDT CHEATSHEET

\(A = [\,\mathbf a_1\;\cdots\;\mathbf a_n\,]\), independent columns; for \(j = 1,\ldots,n\):

1 Start \(\mathbf v_j \leftarrow \mathbf a_j\).
2 Project For \(i < j\): \(r_{ij} = \langle \mathbf q_i,\,\mathbf a_j \rangle\); \(\mathbf p_j = \operatorname{proj}_{U_{j-1}}(\mathbf a_j) = \sum_{i<j} r_{ij}\,\mathbf q_i\), with \(U_{j-1} = \operatorname{span}\{\mathbf q_1,\ldots,\mathbf q_{j-1}\}\).
3 Residual \(\mathbf v_j \leftarrow \mathbf a_j - \mathbf p_j;\qquad \mathbf v_j \perp U_{j-1}\).
4 Normalize \(r_{jj} = \lVert \mathbf v_j \rVert > 0;\qquad \mathbf q_j = \mathbf v_j/r_{jj}\).
QR Collect \(Q = [\,\mathbf q_1\;\cdots\;\mathbf q_n\,]\), \(R = (r_{ij})\) upper triangular; \(Q^{T}Q = I\), \(A = QR\).
