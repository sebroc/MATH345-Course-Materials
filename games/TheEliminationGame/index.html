The Elimination Game

step 1 misses 0

  • Decide whether a matrix is in row echelon form.
  • Choose the next row operation: pivot, scale, or clear.
  • Reduce an augmented matrix to REF with elementary row operations.
  • Identify basic and free variables from the pivot columns.
  • Determine whether a system has no solutions, exactly one, or infinitely many.

This course uses leading 1s in REF.

  1. Zero rows are at the bottom.
  2. Each nonzero row starts with a leading 1.
  3. Leading 1s move strictly right as you go down.
  4. Entries below each leading 1 are zero.
  • Variables: Variables in coefficient pivot columns are basic; the other variables are free.
  • Solutions: a contradiction means none; otherwise no free variables means unique, and any free variable means infinitely many.
